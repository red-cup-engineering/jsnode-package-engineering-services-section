## Verified acceptance cases

Specification basis. JSNode fabrication package test plan and module projection. The plan selects only the owning package's tests and preserves declared requirements. A projected catalog is a declaration executed by the existing Node.js interpreter.

| Case | Check | Behavior |
| --- | --- | --- |
| ` JSNODE-PACKAGE-REQUIREMENTS ` | source refusal | A test requirement declaration must identify a test owned by the package and name a valid requirement. |
| ` JSNODE-PACKAGE-CATALOG ` | source invariant | A module specification deterministically produces a shared module and a native NDJSON catalog without wrappers. |
| ` JSNODE-PACKAGE-QUICKSTART ` | consumer example | An installed consumer receives a test plan that omits fixtures and child-package tests while retaining test requirements. |

Runtime requirement. ` >=24 `
